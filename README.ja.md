# OpenJLPT-ZH-premium

[OpenJLPT](https://github.com/evanclan/OpenJLPT) から派生した独立プロジェクトです。AntaresGG が中国語の学習内容、フラッシュカードの進捗保存とシャッフル機能を保守しています。

N3・N2・N1 の語彙と文法はすべて中国語化済みです。N5/N4 は一部のみ対応しています。項目 ID、Python の `openjlpt` インポートと CLI は互換性のため維持しています。

配布は [GitHub Releases](https://github.com/AntaresGG/OpenJLPT-ZH-premium/releases) で行います。独立版は npm/PyPI にまだ公開していません。上流の `openjlpt` パッケージと混同せず、インストールと運用は [README](README.md) を参照してください。

原著者と各データ源への帰属を保持しています。[LICENSE](LICENSE)、[NOTICE](NOTICE.md)、[CITATION](CITATION.cff) を参照してください。
